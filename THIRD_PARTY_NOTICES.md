| --- | --- | --- |

| `scripts/` (benchmarking, validation and data-generation scripts) | Independently written for QwenForge by the maintainer; **not** copied from the Summer School evaluation scripts | Covered by the project's MIT license |

The project maintainer has confirmed that the repository may be published. This notice acknowledges the source of the original assignment text without representing that QwenForge owns or relicenses that text. Readers should not interpret the top-level MIT license as a new license grant for the original Summer School assignment. For reuse beyond reading the copy published here, follow applicable rights and permissions from the original rights holders.

The documented performance results were produced in a Summer School evaluation setting. This benchmark context should not be confused with authorship of QwenForge's implementation, evaluation scripts or generated workloads.

If a specific file contains other third-party portions requiring attribution, please open a documentation issue with the file path and relevant provenance evidence so the notice can be corrected.
